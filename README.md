# UnfoldK — Your Pass to Korean Culture

All-in-one platform for Hallyu fans worldwide.

🌐 [unfoldk.com](https://unfoldk.com)

## Services

- **HallyuCalendar** — K-pop comebacks, K-drama releases, and global tour dates in one calendar.
- **KpopStats** — Real-time artist analytics: subscribers, listeners, and growth trends.
- **KdramaMatch** — Personalized K-drama recommendations and a viewing tracker.
- **HangeulGo** — Learn Korean through drama lines, daily expressions, and quizzes.
- **KfoodKit** — Discover K-food from dramas with local-ingredient substitutes and recipes.
- **Curation K** — Curated map of filming locations, attractions, and food spots across Korea.

## Tech Stack

- **Frontend** — Next.js (App Router), TypeScript, Vercel
- **Backend** — FastAPI (Python), Railway
- **Database & Auth** — Supabase
- **AI** — Claude API
